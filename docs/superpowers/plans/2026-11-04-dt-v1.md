# dt 1차 버전 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 3D 모델 업로드 → 층 지정 → 장치 배치 → 연동 키로 이벤트·위치 수신 → 3D 알람·대시보드까지 동작하는 오픈소스 3D 관제 웹앱 1차 버전을 만든다.

**Architecture:** pnpm 모노레포다. `packages/shared`의 zod 스키마와 상수를 서버·화면·시뮬레이터가 공유한다. Fastify 서버 한 대가 REST API, WebSocket, 화면 정적 파일을 모두 제공한다. 이벤트·알람은 PostgreSQL(테스트는 PGlite)에 저장하고, 객체 위치는 서버 메모리에만 둔다. 화면은 React + react-three-fiber로 만든다. 모델을 불투명·반투명 두 벌로 그리고, 클리핑 평면으로 층을 나눈다.

**Tech Stack:** Node 24 LTS, pnpm 10, TypeScript 5, zod 4, Fastify 5 (`@fastify/websocket`, `@fastify/multipart`, `@fastify/cookie`, `@fastify/static`, `@fastify/swagger`, `@fastify/swagger-ui`, `fastify-type-provider-zod`), Drizzle ORM + drizzle-kit, `pg`, `@electric-sql/pglite`, `@gltf-transform/core|extensions|functions`, `gltf-validator`, `meshoptimizer`, `draco3dgltf`, `@aws-sdk/client-s3`, React 19, Vite, react-router 7, TanStack Query 5, zustand 5, three, `@react-three/fiber` 9, `@react-three/drei` 10, `three-mesh-bvh`, Tailwind CSS 4, react-i18next, Recharts, Vitest, Testing Library, Playwright, tsup, tsx.

**Spec:** `docs/superpowers/specs/2026-11-04-dt-v1-design.md`

## Global Constraints

- **회사·제품 중립:** 코드, 주석, 문서, 커밋 메시지, 브랜치 이름, 샘플 데이터에 특정 회사의 내부 제품명·시스템명, 사내 주소, 고객 정보, 실제 건물 도면을 넣지 않는다(스펙 3장 반목표).
- **언어:**
  - 코드, 식별자, 커밋 메시지는 영어로 쓴다.
  - 화면 문구는 i18n 키로만 쓴다. `en`이 기본이고 `ko`를 함께 둔다.
  - README는 `README.md`(영어)와 `README.ko.md`(한국어)를 둔다. 나머지 문서는 한국어로 쓴다.
- **폐쇄망:**
  - 런타임에 외부 네트워크를 호출하지 않는다. CDN, 웹폰트, 원격 디코더·폰트 모두 금지다.
  - 폰트는 시스템 폰트 스택을 쓴다.
  - drei `<Text>`(troika)는 원격 폰트를 불러오므로 금지한다. 3D 라벨은 캔버스 텍스처로 만든다.
  - Meshopt 디코더는 `three/examples/jsm/libs/meshopt_decoder.module.js`를 번들에 넣어 쓴다.
- **비밀값:** 커밋하지 않는다. 설정은 환경변수로 받고 `.env.example`에 안내한다.
- **의존성:**
  - 설치 시점의 최신 안정 버전을 쓰되, 메이저 버전은 Tech Stack 표기에 맞춘다. lockfile은 커밋한다.
  - `@dt/shared`는 TS 소스를 그대로 export한다(`"exports": {".": "./src/index.ts"}`). 서버는 tsup으로 shared까지 함께 번들한다.
- **상수:** `packages/shared/src/constants.ts`에 아래 값을 둔다.
  - `ALARM_CONTINUATION_MS = 10_000`
  - `OBJECT_HOLD_MS = 1_000`
  - `OBJECT_FADE_MS = 3_000`
  - `OBJECT_TTL_MS = 4_000`
  - `OBJECTS_BROADCAST_INTERVAL_MS = 200`
  - `MAX_POSITION_BATCH = 1_000`
  - `FUTURE_TOLERANCE_MS = 300_000`
  - `FLOOR_CEILING_CUT_M = 0.5`
  - `FLOOR_BASE_SLACK_M = 0.05`
- **페이드 규칙 (계획 단계 해석):** 스펙의 "정보가 더 오지 않으면 3초 동안 투명해지며 사라짐"과 "최소 1초에 한 번 전송"을 합쳐 해석했다.
  - 마지막으로 받은 뒤 1초까지는 불투명하게 유지한다.
  - 이후 3초 동안 선형으로 투명해진다.
  - 받은 지 4초가 되면 제거한다.
- **알람 이어짐 판단:** dt가 받은 시각을 기준으로 한다(계획 단계 결정). 통계는 발생 시각을 기준으로 한다(스펙 6.9).
- **심각도:** `critical > major > minor > info` 순이다. 연동 키 기본값의 초기값은 `critical`이다.
- **좌표:** API 평면 좌표는 `x = 모델 X`, `y = −모델 Z`이고 단위는 m다. 모델은 glTF Y-up이다.
- **장치 방향:**
  - `yawDeg`는 평면 +y(북)를 0으로, +x(동) 쪽으로 도는 각도다.
  - `pitchDeg`는 양수가 위쪽이다.
  - 모델 회전은 Euler 순서 `'YXZ'`, `rotation.y = −yaw`, `rotation.x = pitch`(라디안)다.
- **층 렌더 구간:**
  - 선택한 층의 불투명 구간은 `[elevationMin − 0.05, elevationMax − 0.5]`다. 위층 슬래브(천장)를 잘라서 위에서 층 내부가 보이게 하기 위해서다.
  - 나머지 부분은 반투명으로 그린다.
- **레이캐스트와 클리핑:** three.js 레이캐스트는 클리핑을 무시한다. 그래서 3D 피킹, 바닥면 찾기, 좌표 표시는 모두 `pickFloorHit`으로 층 구간 안의 결과만 걸러서 쓴다.
- **규모 목표 (스펙 6.15):**
  - 현장 10개, 현장당 장치 200개
  - 한 현장에 동시에 보이는 객체 300개를 내장 그래픽에서 30fps로 표시
  - 위치 메시지 초당 500건, 이벤트 메시지 초당 20건
- **API 오류 응답 형식:** `{ code: string, message: string, details?: unknown }`. zod 검증 실패는 400 `validation_error`다.

## Review Focus

1. **같은 상황의 이벤트가 동시에 여러 건 올 때:** 알람은 하나만 생기고 횟수는 정확해야 한다. → Task 10 `merges 20 concurrent identical events into one alarm`
2. **시간대 없는 시각, 5분 넘게 미래인 시각:** 400으로 거부해서 연동 업체의 시계 버그를 연동 단계에서 잡는다. → Task 1 `occurredAt must carry a timezone`, Task 10 `rejects occurredAt more than 5 minutes ahead`
3. **단위가 cm·mm인 모델 (높이 수백 m):** 이상한 층을 조용히 제안하지 말고 경고를 돌려준다. → Task 5 `warns when model looks like centimeters`
4. **장치가 놓인 층을 층 편집에서 지우려 할 때:** 409로 막고 어떤 장치 때문인지 알려준다. → Task 6 `refuses to drop a floor that devices use`
5. **서버 재시작이나 네트워크 끊김 뒤 재접속:** 다시 구독하고, 스냅샷으로 객체·알람을 통째로 교체해서 유령 마커가 남지 않게 한다. → Task 18 `snapshot replaces stale objects`, `reconnect resubscribes`

  expect(ok(EventMessageSchema, base)).toBe(true);

    expect(ok(EventMessageSchema, rest)).toBe(false);
  }

  expect(ok(EventMessageSchema, { ...base, occurredAt: '2026-11-04T09:00:00' })).toBe(false);
  expect(ok(EventMessageSchema, { ...base, occurredAt: '2026-11-04T00:00:00Z' })).toBe(true);

  expect(ok(EventMessageSchema, { ...base, severity: 'urgent' })).toBe(false);

### Task 5: 모델 처리 (검증, 압축, 층 높이 제안, 단위 경고)

**Files:**
- Create: `apps/server/src/models/processModel.ts`, `apps/server/src/models/floorSuggestion.ts`
- Test: `apps/server/test/models.test.ts`

**Interfaces:**
- Consumes: `samples/office-3f.glb`, `FloorRange`, `ModelWarning`
- Produces:
  - `processModel(input: Uint8Array): Promise<ProcessedModel>`
  - `ProcessedModel = { glb: Uint8Array; floorSuggestion: FloorRange[]; warnings: ModelWarning[]; bounds: { min: [number,number,number]; max: [number,number,number] } }`
  - `class ModelError extends Error { code: 'not_glb'|'invalid_gltf'|'unsupported_extension'; details: string[] }`
  - `suggestFloors(doc: Document): FloorRange[]`

**처리 순서:**
1. 앞 4바이트가 `glTF`가 아니면 `not_glb`로 거부한다.
2. `gltf-validator`의 `validateBytes`에서 오류가 1개 이상이면 `invalid_gltf`로 거부한다. `details`에는 앞 5개 메시지를 담는다.
3. `NodeIO`에 `ALL_EXTENSIONS`를 등록하고, `draco3d.decoder`와 meshopt decoder·encoder 의존성을 붙여 읽는다.
4. 허용하지 않는 확장(`KHR_texture_basisu` 등 화면에서 별도 wasm 디코더가 필요한 것)이 있으면 `unsupported_extension`으로 거부한다.
5. 층 높이 제안과 범위(bounds)를 계산한다.
6. `KHR_draco_mesh_compression` 확장을 제거하고 `dedup()`, `weld()`, `meshopt({ encoder })`를 적용해 GLB로 쓴다.
7. 단위 경고: 높이(bounds Y 범위)가 300 초과면 `units_suspect_too_large`, 1.5 미만이면 `units_suspect_too_small`을 붙인다.

**층 높이 제안 알고리즘 (`suggestFloors`):**
1. 모든 메시 프리미티브의 삼각형을 월드 좌표로 바꾼다. 위를 향하는 면(법선 y ≥ 0.95)만 골라, 면적을 높이별 0.1m 칸에 더한다.
2. 가장 큰 칸 면적의 20% 이상인 칸만 후보로 남기고 높이순으로 정렬한다.
3. 1.5m 안에 있는 후보끼리는 면적이 큰 쪽만 남긴다. 남은 높이를 `levels`라 한다.
4. `levels`가 2개 미만이면 `[{bounds.minY, bounds.maxY}]`를 반환한다.
5. 그렇지 않으면 연속한 두 높이를 층 하나로 묶는다. 마지막 높이와 `bounds.maxY`의 차이가 2m 이상이면 `{last, maxY}` 층을 하나 더 붙인다.
